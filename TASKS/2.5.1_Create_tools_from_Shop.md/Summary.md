# Summary of `T.ctfs` Create tools from Shop.md

Every tool kind in `examples/shop/tools.toml` is built from the shop
files (`unique_id`, `holder`, 14 tools, each within 2 % of its
profile's volume), grid plates have a shop kind, and the STEP cache
(`model_cache.py`) makes repeat builds fast.  Closed 2026-11-22 with
`T.tm~2.5` (#402): kinds for vises, parallels and tables, and
modeling from the shop, continue in `T.tfo~6.5` and `T.tkis~6.7`.

Tags: `T.tm~2.5`, `T.tfo~6.5`, `T.tkis~6.7`.
