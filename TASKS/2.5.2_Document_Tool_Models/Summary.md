# Summary of `T.dtm` Document Tool Models

`Tool_Models.md` and `docs/tool_models/*.svg` are generated by
`tooling/tool_models.py`: a page per cutter kind (end mill, drill,
chamfer, corner rounding, double angle, countersinks) and for the
machine vise, jaw plate, parallel and grid plate, each with SVG
views, a letters table (one meaning per letter on every model), the
Python interface from the source and the JSON description; a test
keeps it in step.  Closed 2026-11-22 with `T.tm~2.5` (#402): once
tools come from outline files, their `.outline.svg` and letters
table are the pages (`T.tfo~6.5`, `T.oe~6.2`).

Tags: `T.tm~2.5`, `T.tfo~6.5`, `T.oe~6.2`, `T.sdfm~2.5.2.1`.
